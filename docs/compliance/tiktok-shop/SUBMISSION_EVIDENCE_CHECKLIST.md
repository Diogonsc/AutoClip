## Capture procedure

1. Use a fresh browser session and the official Partner Center URL reached by the owner. Do not share login credentials or recovery codes.
2. Open the rejected review case and record its reference in the owner's private evidence register, not in public repository documents.
3. Capture the entire relevant question text, current Yes/No selection, and any reason/attachment state in one authentic screenshot when possible. Do not recreate the form in an editor.
4. If the question is not explicit or the selected Yes cannot be supported by actual controls, pause and correct the truthful form response before resubmission.
5. Attach the owner-approved standard and only supporting evidence that corresponds to implemented controls. Label local tests as local; do not present them as Cloud evidence.
6. Save the original screenshot and file hash in access-controlled storage. Create a redacted copy only when needed; retain a record of redactions.
