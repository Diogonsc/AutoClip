### Falhas demonstradas versus riscos potenciais

- **Falha demonstrada no repositório/ambiente:** diferença observada entre signatures/RPCs Cloud e a hardening local pendente; ausência dos nove IDs no ledger snapshot; `authenticated EXECUTE` nos metadados; rotinas de refresh locais não serializam/persistem com CAS; nenhum teste de integração do TokenStore concorrente.
- **Riscos potenciais, não exploração provada:** elevação de plano ou resolução indevida de job via corpo RPC remoto; SSRF/abuso de `pg_net`; leitura/escrita cross-tenant por ACL DELETE; publicação baseada em mídia não validada; perda de refresh token por corrida; exclusão prematura de mídia.
- **Não verificado:** secrets e painel, Data API exposed schemas, egress, cron command/active schedules, conteúdo de rotinas, RLS runtime Cloud, storage policy behavior, OAuth provider current contract, backup/restore e deploy Edge.
